# Story template

## Title

`[type] concise observable outcome`

## Description

```markdown
## Context
Why this story exists and its project location.

## Outcome
Observable behavior delivered by this story.

## Acceptance criteria
- [ ] Testable criterion.
- [ ] Regression or compatibility criterion.
- [ ] Required validation completes.

## Technical notes
Relevant patterns, boundaries, and likely files.

## Exclusions
Work intentionally outside this story.

## Dependencies
Friday item IDs or `none`.

## Validation
Exact commands or evidence expected.
```

Prefer three to seven criteria. Avoid implementation trivia unless required.
