# Project context brief

Return these fields:

- Repository root.
- Request interpretation.
- Applicable instruction files, ordered by scope.
- Architecture and relevant components.
- Existing patterns to preserve.
- Required commands and validation matrix.
- Git state, remotes, and likely target branch.
- Dirty or conflicting user changes.
- Material unknowns and their impact.
- Suggested story boundaries.

Label every unverified conclusion as an assumption.
