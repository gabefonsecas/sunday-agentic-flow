# Agentic Dev Flow

Use the bundled skills for managed development work.
Automatically start `orchestrate-development-task` for development requests.
Never require the user to name a skill or provide a workflow prompt.
Read every applicable `AGENTS.md`, `GEMINI.md`, and project rule first.
Treat Friday as the source of workflow state.
Never claim a transition, push, or PR without verifying it.
Route discovery to the fast remote tier.
Route implementation to the balanced remote tier.
Route architecture and final review to the deep remote tier.
Keep external mutations under the primary agent.
